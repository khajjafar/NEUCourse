# Log 18: Fixing Course Routing & Re-Architecting Search

**Timestamp:** 2026-03-03T10:00:00Z

## Modifications Made

1. **Fixed URL Encoding Bug in Course Routing (`/app/api/v1/courses/[courseId]/route.ts`)**
   - **Problem:** Opening a class after searching failed with `Course CS%205002 not found.` Next.js doesn't decode dynamic path segments for API routes inside \`params\` automatically if they come from heavily encoded links on the client. Additionally, the existing documents in Firestore had new document IDs like \`CS5002\`.
   - **Fix:** Implemented \`decodeURIComponent()\` and a robust \`.replace(/[\\s\\-]+/g, '').toUpperCase()\` normalization on the \`courseId\` parameter to ensure it perfectly matches the schema generated by the scraper.

2. **Implemented Node.js Memory Caching for Search API (`/app/api/v1/courses/route.ts`)**
   - **Problem:** The system was sending a Firebase Admin SDK query to download all 2785+ courses (over 3MB of JSON) on *every single keystroke*.
   - **Fix:** Built a server-side memory cache with a 1-hour TTL. Now, all 2785 courses are kept in memory and filtering executes instantly in milliseconds instead of hitting the database network. Also limits JSON output to 50 results to prevent slowing down the client browser render cycle.

3. **Enhanced Search Algorithm & Added Level Filters (`/app/api/v1/courses/route.ts` & UI)**
   - **Problem:** Users could only do basic text matches, making it hard to find courses.
   - **Fix:** 
     - Modified the search algorithm to check for exact course ID matches (e.g. "CS2500" perfectly matches).
     - Modified the number search to use prefix matching if parsing numbers (e.g. typing "25" matches "2500").
     - Added a new \`level\` query parameter on the backend to filter 1000-level vs 2000-level courses.
     - Updated \`app/courses/page.tsx\` to introduce a new "Course Level" dropdown UI next to the Department filter.
     - Updated \`useCourseSearch.ts\` React hook to handle the state and integrate it with the \`/api/v1/courses\` endpoint accurately.
